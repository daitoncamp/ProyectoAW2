# Sistema para Asociaciones Estudiantiles

## Descripción

Este proyecto consiste en el desarrollo de una API REST para la gestión de asociaciones estudiantiles universitarias.

El sistema permitirá administrar:
- estudiantes miembros,
- inversiones y aportes,
- eventos organizados por la asociación.

Además, busca mejorar la organización y transparencia en el manejo de información financiera y actividades estudiantiles.

---

##  Problema

Actualmente muchas asociaciones estudiantiles gestionan eventos y fondos mediante:
- grupos de WhatsApp,
- hojas de cálculo,
- registros manuales.

Esto genera:
- pérdida de información,
- desorganización,
- poca transparencia,
- y dificultades para controlar eventos y aportes.
